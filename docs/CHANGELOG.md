# Changelog OUTDOOR PhotoSorter

## 2026-11-08 — карточки, Образцы и единый CPU-бюджет
- Карточки ФО, очереди и результатов получили статусные обводки. «Удаляется» окрашивает всю карточку в красный цвет и скрывает конфликтующие действия, «Ошибка удаления» имеет только красную обводку. ZIP остаётся частью «В обработке».
- В Образцах единое модальное окно для стандартного формата, безопасных индивидуальных названий и строгого массового импорта папок. Новые записи каталога можно создавать пустыми; фото проходят прежнюю очередь и публикацию версии MegaLoc.
- Объединены параметры CPU ФО/Образцов в один budget для очереди. Доступные CPU определяются сервером; worker применяет CPU affinity и число потоков в начале каждого задания. Миниатюры/очистка используют низкие относительные CPU shares без прежних фиксированных квот. Логика ZIP не менялась.
- Добавлены серверные тесты и Playwright регрессии для конструкций, CPU, удаления и новых элементов UI.

## 2026-11-08 — TCP BBR при развёртывании
- Установщик при запуске из-под root пробует включить Linux TCP BBR, закрепляет модуль и sysctl для перезагрузки, не трогая qdisc `fq_codel`.
- Отсутствие модуля или прав не останавливает установку; доступны read-only проверка, отключение автоматической настройки и отдельная команда отката.
- Регрессионные тесты изолируют host sysctl, проверяют отсутствие изменений при проверке, пропуск, отказ ядра, активацию и откат.


## 2026-11-08 — доведение интерфейса, ZIP и хранения
- Подтверждены ранее реализованные: упрощённая загрузка ФО, независимая прокрутка Образцов, компактные карточки, финальный этап ZIP и отдельные CPU-настройки для ФО/образцов.
- ZIP публикуется после проверки числа файлов и CRC; отсутствующий полный ZIP можно подготовить повторно через API и интерфейс без пересчёта MegaLoc.
- Выключение автоудаления ставит на паузу и ранее назначенные сроки. При повторном включении просроченные партии получают новый полный срок; новые обработки отсчитывают хранение после готовности ZIP.
- В карточки ФО возвращены фактические счётчики групп и неопределённых фотографий; сводка не передаёт внутренние пути.
- Новые регрессионные тесты проверяют ZIP-восстановление, переключение автоудаления и данные карточек.
- Изменения пока только в GitHub `main`: рабочий VPS обновляется отдельно после проверки резервной копии.

## Beta — исправления списка ФО и выбора обработки
- На обработке доступны готовые партии без истории запусков; завершённые партии можно обработать повторно. Отсутствующий `runs` принимается за 0.
- Списки и счётчики ФО не включают завершённые удаления. Во время удаления запись видна со статусом, а интерфейс обновляет список до завершения.
- Возобновление прерванных загрузок не создаёт лишнюю партию при старом ответе API без `runs`; выбор новой папки очищает предыдущую локальную привязку.
- Регрессионные тесты: реальная disposable PostgreSQL, Vitest и Playwright.

## Beta 0.1.0-beta.1 — main
- Единственный Vue 3 сайт на `/`, разделы `/fo`, `/references`, `/processing`, `/results`, `/logs`, `/settings`, `/login`.
- Старый `frontend/static` удалён; `/v3/` и `/static/*` не обслуживаются. Единственный источник кода — `main`. Vite, Vue Router, Playwright, pytest и Docker smoke проверяют единый root-адрес.
- API, PostgreSQL, MegaLoc math и физические фотографии не изменяются этой правкой GitHub. Live VPS обновляется отдельно.


## История разработки: проверка безопасности, backup и rollout
- CLI `snapshot.py`: согласованный снимок данных, PostgreSQL custom dump, Models/models+cache, учет Hard Links, SHA-256, verify и только изолированное восстановление.
- CI PostgreSQL17: реальный pg_dump→pg_restore на disposable DB, восстановление тестовых фото/Образцов, контроль записи и inode.
- `compare_baseline.py`: детальный diff SAM/group/uncertain/score/candidate ranking + ZIP CRC, не требует нейросети.
- 1315 синтетических ФО + ZIP/SAM/cleanup/retention regression; отделено от реального 6.4 GiB benchmark.
- `staging_probe.py`: только GET, p50/p95, RPS, возможные реальные service/disk и docker stats для staging.
- Безопасный `install.sh --check`, восстановление секретов, no credential reset/up без подтверждённого backup.
- Security: login throttling, rejection of 30M+ pixel bombs, ZIP Slip and historical SAM path protection.
- Миграция `0007_service_heartbeat.sql`, процессный heartbeat и UI статус трёх служб; исправлен парсер SQL комментариев.
- Не меняет MegaLoc math, не перезаписывает старые ZIP/UI, не трогает VPS.
