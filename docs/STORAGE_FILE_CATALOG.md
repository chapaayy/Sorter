## Verified dependency findings (base SHA)
- database.py: users.id BIGINT identity; sessions.user_id CASCADE; batches currently UUID and no owner; uploads.batch_id CASCADE, jobs.batch_id required without cascade. Introduce explicit non-cascading batches.owner_id; do not infer ownership from result_access_grants. access_policy.is_owner requires username admin and owner role; viewer GET/HEAD whitelist and require_published join grants, jobs, active batch. Preserve policy; do not generalize permissions.
- uploads.target_path and uploads.media_output_path (0029), reference_import_files.stored_path (0014), reference_version_members.target_path (0013), reference_cache.cache_path (base schema), jobs.snapshot JSONB and manifest fields query/reference/copy require typed key conversion. Relative upload manifest paths and reference import relative_path are display/transfer metadata, not authority. 35 migration files (0001–0036, no 0017) inspected for relationship/path candidates; no migrations changed.
- reference_objects currently uses session UUID/files/upload UUID + extension, not content-addressed SHA. Part under session incoming; verify digest before publication; new content-addressed objects require member path rework. Preserve current/history/pins and import dependencies; no legacy file migration.
- exporter writes manifest.json + manifest.rows.jsonl + manifest.csv. result_pages iter_rows/page prefer JSONL and fallback load_model JSON; pagination cursor is byte offset for JSONL vs row index for fallback. Stage 3 canonicalization must preserve pagination/API, check archive/repository consumers and remove CSV only after confirming export needs. atomic_json uses adjacent mkstemp and os.replace; stage 2 common helper must preserve atomic semantics.
- database.save_snapshot persists jobs.status/snapshot, finishes FIFO for terminal state and schedules retention for completed/completed_with_errors plus archive_state ready/on_demand. Do not make ZIP a completion gate.
- operations.start locks active batch FOR SHARE and inserts batch_operations heartbeat; temp_cleanup rechecks unfinalized row FOR UPDATE, 30-day DB age and mtime, no batch lease or active job. Preserve safety, strengthen ownership and crash accounting.
- media/video.py has three unnamed TemporaryFile calls (L30, L86); services/thumbnails.py L105 uses TemporaryDirectory without explicit dir. These must be routed, not only named media files.
- map_updater.py L103 checks archive_retries.state='running' in verify_idle even though archive_retries service no longer enqueues jobs. Stage 6 must remove obsolete dependency only after caller/schema audit. Dockerfile HF_HOME/HF_HUB_CACHE/HF_XET_CACHE/TORCH_HOME point into Models/cache; prove working model offline before any cache purge.
