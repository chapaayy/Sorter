# Утверждённая дизайн-система (будущий этап 3, сейчас не внедрена)

В текущей stage1 ветке остаётся старый `frontend/static/`. Дизайн ниже фиксирует уже согласованные требования, **не является заявлением о готовом UI**.

- Тёмная графитовая тема по умолчанию и светлая тема; спокойный зелёный акцент. Токены CSS: `--page`, `--sidebar`, `--panel`, `--panel-alt`, `--border`, `--text`, `--muted`, `--accent`, `--danger`.
- Навигация: `ФО / Образцы / Обработка / Результаты / Логи / Настройки`. Ненужную отдельную «Главную» не добавлять.
- Списки ФО/запусков/результатов — широкие **фиксированные строки ~100–110px**. Место статуса/процента миниатюр не меняет высоту.
- ФО: список партий → **отдельная** галерея одной партии; обычные фото только через миниатюры, оригинал по клику.
- Образцы: на ПК слева SAM список, справа его фото; на мобильном сверху select, снизу галерея. Без отдельных экранов для SAM.
- Результаты: список запусков → **двухпанельный** просмотр по SAM/группам; `_Неопределено` заметен; основная кнопка ZIP целиком, подтверждение архив сохранён, дата retention и сильное предупреждение «удалить всю партию».
- Все интерактивные компоненты переиспользуемые: `RowCard`, `Panel`, `Button`, `ThumbnailGrid`, `ImageViewer`, `ConfirmDialog`, `Toast` и т. д. Навигация keyboard/mobile ≥44 px.
- Прогресс нейросети — по реальным стадиям/измерениям, никакого вымышленного «общего процента».
- Реализация UI — **этап 3**, после независимых миниатюр, очереди и логов этапа 2.

См. исходное ТЗ для детального UX, палитры и сценариев.
